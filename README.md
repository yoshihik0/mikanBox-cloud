# 🍊mikanBox Cloudflare版

[English README →](README_en.md)

**AI時代のパーツ組み立て型・超軽量CMS**

🍊mikanBoxは、使いやすいUIと、Markdownによるコンテンツ管理、コンポーネントを組み合わせて柔軟に構築できる設計をもち、これらをAIによって自在にコントロールできる超軽量CMSです。

このリポジトリは、Cloudflare WorkersとD1の上で動く **Cloudflare版**（🍊mikanBox Cloud）です。管理画面と公開サイトを別々のWorkerで運用し、公開サイトは静的ファイルだけで配信します。

> [!NOTE]
> Cloudflare版は開発中です。機能と対応状況は[Cloud版マニュアル](docs/cloud_ja.md)を確認してください。

---

## 3つのバージョンと使い分け

🍊mikanBoxには、動かす場所と保存方法の違う3つのバージョンがあります。

| | 📂 flat | 🗄️ SQLite版 | ☁️ Cloudflare版（本リポジトリ） |
| :--- | :--- | :--- | :--- |
| 主な用途 | ページ数の少ないサイト（〜100ページ程度） | ページ数を増やしていくサイト | Cloudflare上で管理・公開したいサイト |
| 動く場所 | PHPが使えるサーバー、または手元のPC | PHPが使えるサーバー、または手元のPC | Cloudflare Workers |
| ストレージ | jsonファイル | SQLite（単一DBファイル） | D1（画像は必要に応じてR2） |
| 動作要件 | PHP 8.0以上 | PHP 8.0以上 + SQLite3拡張 | Cloudflareアカウント、Node.js |
| 公開サイトの配信 | 動的・静的・混在 | 動的・静的・混在 | 静的ファイルのみ（閲覧時にWorkerもD1も動かない） |
| ログイン方式 | パスワード | 登録した端末（パスワードなし） | 登録した端末（パスワードなし） |

> [!TIP]
> **ローカルで動かして、静的サイトとしてアップするだけなら、flat（または SQLite版）で十分です。** 手元で管理し、書き出したHTMLをレンタルサーバーやCloudflareなどに置けば、公開側にPHPも管理画面も不要です。
> **管理そのものをCloudflare上で行いたい場合に、Cloudflare版をお使いください。** どこからでも管理画面にアクセスでき、サーバーを用意せずに管理と公開を運用できます。D1を使用すれば、支払い方法の登録なしで無料枠の範囲からはじめられます（条件に制限はあります）。

- [🍊mikanBox flat →](https://github.com/yoshihik0/mikanBox-flat/)
- [🍊mikanBox（SQLite版） →](https://github.com/yoshihik0/mikanBox)

## 特長

- **Cloudflare上で完結** — 管理画面・MCP・データ（D1）・公開サイトをCloudflareにまとめて運用
- **管理と公開の分離** — 公開側は静的ファイルのみ。公開側にプログラムもデータもなく、閲覧でWorkerやD1の利用枠を使わない
- **モードレスUI** — ページ遷移なし、1画面でほぼ全作業完結。軽快な操作感（PHP版と揃えて開発）
- **Markdown対応** — コンテンツを簡単に編集可能、情報のアーカイブとしても適している
- **カテゴリで絞り込み** — ページや画像をカテゴリで絞り込み、ワークスペースとして利用できる
- **ファイル名だけで画像表示** — ファイルのパスを意識せずに画像を張り込める
- **コンポーネント構造・スコープCSS** — 組み合わせて利用できるページテンプレートやパーツ、干渉を気にしないCSS
- **AI生成コードをそのまま配置可能** — 手作業でのデザインなしでの運用にも対応
- **AIエージェント連携（MCP）** — AIがサイト構造やデザイン基調などを理解し、直接ファイルを読み書き
- **DESIGN.mdの管理** — AIへの指示もサイトで管理し、AIに伝えられる
- **DB Less DB** — ページにデータを埋め込んでAPIで出力。ヘッドレスCMSにも
- **画像はD1から始めてR2へ移行可能** — 最初はD1だけで利用でき、容量が必要になったらR2へ移行
- **バックアップと持ち出し** — JSONバックアップと復元、静的HTMLのZIP出力

## インストール

AIにインストールを依頼する方法と、自分でコマンドを実行する方法があります。

**AIに依頼する場合**

ファイルの取得やコマンド実行ができるAIを使い、作業フォルダで新しい会話を開いて、次のように依頼します。

```
https://github.com/yoshihik0/mikanBox-cloud からCloudflareにインストールしてください
```

AIがファイル取得・設定・配置を進め、利用者はCloudflareの認可、アドレスの選択、普段のブラウザでの初回端末登録を行います。画面を見ながら進められる[画像付きインストールガイド](public/mikanbox/guides/install-ja.html)もあります。

**自分で行う場合**

1. [リリース一覧](https://github.com/yoshihik0/mikanBox-cloud/releases)から **Source code (zip)** をダウンロードして展開
2. 展開したフォルダで `npm ci`、`npx wrangler login` を実行し、設置するCloudflareアカウントを確認
3. D1の作成、設定ファイルの用意、デプロイを実行
4. 公開サイトのアドレスを開き、初回の端末を登録

2以降の詳しいコマンドと設定は、[新規インストールと公開](docs/cloud_ja.md#新規インストールと公開)を参照してください。設定ファイルと秘密情報はGitHubに公開しないでください。

パスワードはありません。管理画面に入れるのは、登録した端末（ブラウザ）だけです。端末の追加や、すべての端末を失ったときの復旧は、[マニュアル](docs/cloud_ja.md#端末認証)を参照してください。

## 基本的な使い方

### ページの公開ステータス

| ステータス | 動作 |
| :------- | :------- |
| 下書き | 非公開（ログインした編集者のみプレビュー可） |
| 承認待ち | 非公開（ログインした編集者のみプレビュー可） |
| 公開 | ビルドで静的HTMLを作成し、静的ファイルとして配信 |
| DB | ページ自体は非公開。データをAPI（`/api/ページID`）として公開 |

ページごとの静的・動的の選択はありません。公開をやめたページは、ビルド時に配信先から取り下げます。

（プレビューは動的に生成されているので、動的なサイトの構築を可能にすることもできますが、セキュリティや無料枠で利用しやすいようにするために、動的公開機能の搭載は、現段階ではおこなっていません。）

### 静的サイト生成（ビルド）

ページ一覧の下のビルドボタンで、公開ページを静的HTMLとして生成し、公開側へ配信します。変更のあったファイルだけを送ります。

### 画像（D1とR2）

最初はR2なしで、画像をD1に保存して使えます（画像合計400 MBまで、1画像10 MBまで）。容量が必要になったら、管理画面の「D1からR2へ移行」でR2へ切り替えられます。どちらも公開URLは `/media/ファイル名` です。

R2へ移行するには、Cloudflare側で、支払い方法の登録が必要です。無料枠がかなりの量ありますが、それを超えると課金されますので、ご注意ください。

## AIとの連携

PHP版と同じく、AIが生成したHTMLページをそのまま貼り付けて公開でき、AIへの指示（DESIGN.mdなど）もコンポーネントとして管理できます。

- 管理用MCPは `/mcp`（Cloud専用のAPIキーが必要）。ページ・コンポーネント・画像の読み書きができます。
- 公開ヘルプMCPは `/public-mcp`（キー不要・読み取り専用）。
- 人向けのCloudヘルプは `/public-help.html?language=ja` です。

## PHP版との違い

Cloudflare版は、PHP版とUIや操作をそろえることを目標に開発していますが、実行環境の違いによる違いがあります。

- 公開側はプログラムが動かないため、サイト内検索が必要な場合は、Googleのサイト内検索をご利用ください。
- 公開ページはビルドした静的ファイルのみです（「公開（動的）」はありません）。
- 外部取得の `EXT_MD` とD1構成での動画・音声アップロードは未対応です。
- PHP版のSQLiteファイル入出力や移行ツールはなく、バックアップ・復元はJSONで行います。

詳しくは[Cloud版マニュアル](docs/cloud_ja.md)を参照してください。
